Check the health of one or more external systems

## Synopsis

Probes every TARGET concurrently and reports a verdict for each.

A target is an http or https URL. The exit code is governed by
--fail-on, so this command can gate a pipeline step directly.

```
probe-cli check TARGET [TARGET...] [flags]
```

## Examples

```
  probe-cli check https://api.example.com/healthz
  probe-cli check -o json https://a.example.com https://b.example.com
  probe-cli check --fail-on degraded --degraded-after 200ms https://a.example.com
```
