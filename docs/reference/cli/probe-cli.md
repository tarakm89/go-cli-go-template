## Synopsis

A command line application built with Cobra and a hexagonal (ports & adapters) core.

Built on a hexagonal core: the health rules live in internal/core and
every external system is reached through an adapter behind a port.

Telemetry is on by default when an OTLP endpoint is configured. In a
pipeline, set OTEL_EXPORTER_OTLP_ENDPOINT and the run will report its
traces, metrics and logs; a TRACEPARENT in the environment is adopted
as the parent span so the run joins the pipeline's trace.
